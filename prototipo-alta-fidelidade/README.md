# Sabixão - Alta Fidelidade

## Descrição

Este repositório contém os protótipos de alta fidelidade do projeto Sabixão.

## Conteúdo

- **componentizacao.pdf** - Documentação da componentização do sistema
- **telas.pdf** - Protótipos das telas da aplicação

## Sobre o Projeto

Sabixão é um projeto educacional que visa auxiliar estudantes no aprendizado através de uma plataforma interativa e intuitiva. O sistema oferece recursos para organização de conteúdos, acompanhamento de progresso e ferramentas de estudo personalizadas.

### Objetivos

- Facilitar o acesso ao conhecimento de forma organizada
- Proporcionar uma experiência de aprendizado personalizada
- Oferecer ferramentas que auxiliem na retenção de conteúdo
- Criar uma interface amigável e acessível

## Visualização

Os arquivos PDF contêm os designs e a estrutura visual da aplicação, servindo como referência para o desenvolvimento.
